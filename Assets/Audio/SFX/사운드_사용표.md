# Code Defense 효과음 사용표

- 형식: WAV, 44.1kHz, 모노, 16bit. 8비트 칩튠 스타일 (사각파·삼각파·노이즈 합성)
- 넣을 위치: `Assets/Audio/SFX/` (위치는 자유. 이름만 유지)
- Unity 임포트는 기본값 그대로 두면 됨 (.meta 없음, Unity가 자동 생성). 짧은 소리라 Load Type은 `Decompress On Load`(기본값) 권장
- 볼륨은 파일 안에서 미리 맞춰둠: 자주 나는 소리(타워 공격, 타격)는 작게, 알림성 소리(체력 감소, 웨이브 시작)는 크게. AudioSource 볼륨은 전부 1로 두고 시작해서 듣고 조절하면 됨

## 타워 공격음

병영(BarracksTower), 영웅 타워(HeroTower)는 직접 공격하지 않으니 타워 공격음 없음. 거기서 나온 병사·영웅은 아래 유닛 타격음을 씀.

| 타워 | Lv1, Lv2 | Lv3, Lv4 |
|---|---|---|
| ArcherTower | `SFX_ArcherTower_Shoot_Lv12` | `SFX_ArcherTower_Shoot_Lv34` |
| ArtilleryTower | `SFX_ArtilleryTower_Shoot_Lv12` | `SFX_ArtilleryTower_Shoot_Lv34` |
| MagicTower | `SFX_MagicTower_Shoot_Lv12` | `SFX_MagicTower_Shoot_Lv34` |

- 재생 시점: 타워 `Shoot` 애니메이션 1번 프레임 (투사체가 나가는 프레임)
- 투사체가 맞을 때는 소리 없음. 같은 소리 하나로 발사 타이밍만 냄
- 같은 레벨 구간 안에서 차이를 주고 싶으면 Lv2·Lv4에 pitch 1.05~1.1 정도 올려서 재생

## 유닛 타격음

근접 공격(`Attack`)이 상대에게 들어갈 때 재생. 재생 시점은 `Attack` 애니메이션 2번 프레임 (프레임정보.md의 타격 프레임).

| 소리 | 쓰는 유닛 |
|---|---|
| `SFX_Hit_Light` | Soldier Lv1, Lv2 / Enemy_Goblin (경고딱지) / Enemy_Wolf (가출한 마우스) / Enemy_Spider (잠긴 압축파일) / Enemy_ShadowArcher (낚시 메일, 근접 공격할 때) |
| `SFX_Hit_Heavy` | Soldier Lv3, Lv4 / Hero Lv1~4 (고무오리) / Enemy_DarkKnight (철갑 고물 본체) / Enemy_Veznan (협박 메일) / Enemy_VeznanDemon (랜섬웨어 대마왕) |

- Enemy_Gargoyle (떠도는 클라우드)는 공격 동작이 없어서 해당 없음
- Enemy_ShadowArcher의 원거리 `Shoot`은 이번 목록에 소리가 없음. 필요하면 따로 추가
- 보스(Veznan, VeznanDemon)는 `SFX_Hit_Heavy`를 pitch 0.8로 낮춰 재생하면 더 묵직하게 들림

## 기타

| 소리 | 언제 |
|---|---|
| `SFX_Player_Damage` | 적이 출구에 도달해서 플레이어 체력이 깎일 때. 한 프레임에 여러 마리가 들어와도 한 번만 재생 |
| `SFX_Wave_Start` | 웨이브가 출발할 때 (조기 호출 버튼으로 시작할 때 포함) |
| `SFX_Unit_Death` | 모든 유닛 사망. 적 전체, Soldier, Hero. `Death` 애니메이션 시작(0번 프레임)에 재생 |
| `SFX_Tower_Build` | 타워 건설과 업그레이드 둘 다. `Tower_Common_Build` / `Tower_Common_Upgrade` 이펙트 시작과 같이 재생 |
| `SFX_RedLock_Apply` | 보스가 타워를 봉인할 때. `Effect_RedLock_Apply` 시작(0번 프레임)과 같이 재생. 소리 안의 "쾅"이 0.17초 지점이라 Apply 2번 프레임(도장 찍히는 프레임, 12fps)과 맞음 |
| `SFX_RedLock_Break` | 봉인이 풀릴 때. `Effect_RedLock_Break` 시작과 같이 재생 |

- `SFX_Unit_Death`는 적과 아군이 같은 소리. 구분하고 싶으면 아군(Soldier, Hero)은 pitch 1.15, 보스는 0.7로 재생
- RED LOCK이 걸려 있는 동안(`Effect_RedLock_Idle`)은 소리 없음. 루프음은 계속 들리면 거슬려서 뺐음
- LOCKED 팝업은 소리 없음

## 반복감 줄이기 (선택)

자주 나는 소리(타워 공격, 타격, 사망)는 재생할 때마다 pitch를 0.95~1.05 사이에서 랜덤으로 주면 덜 질림.

```csharp
audioSource.pitch = Random.Range(0.95f, 1.05f);
audioSource.PlayOneShot(clip);
```

## 배경 음악

| 파일 | 길이 | 내용 |
|---|---|---|
| `Audio/BGM/BGM_Stage_Loop.wav` | 29.09s (16마디, 132 BPM) | 전투 스테이지용 8비트 루프. A단조. 앞 8마디는 기본, 뒤 8마디는 하이햇이 촘촘해지며 고조 → 다시 처음으로 이어짐 |

- 끝과 처음이 바로 이어지게 만들어서 AudioSource에 `Loop` 체크만 하면 됨. 앞뒤에 무음 없음
- 임포트 설정: Load Type `Streaming` 또는 `Compressed In Memory` 권장 (파일이 2.5MB 정도라 Decompress On Load는 메모리 낭비). Compression Format은 Vorbis(기본값) 그대로. MP3로 변환하면 앞에 짧은 무음이 생겨서 루프가 끊기니 변환하지 말 것
- 볼륨은 효과음보다 작게 맞춰둠. AudioSource 볼륨 1에서 시작해서 0.6~0.8 정도로 조절 추천
