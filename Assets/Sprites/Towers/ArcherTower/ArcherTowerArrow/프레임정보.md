# ArcherTower 투사체·이펙트 프레임 정보

- 모든 시트는 프레임을 가로로 나열. `.meta` 포함 (Unity 6000.3, PPU 60, Point 필터, 압축 없음)
- pivot은 전부 가운데 (0.5, 0.5)
- 투사체 방향: 회전 없음 (글자/구체라 똑바로 날아감)
- 발사 타이밍: 타워 Shoot 시트의 index 1 프레임에서 Projectile 생성
