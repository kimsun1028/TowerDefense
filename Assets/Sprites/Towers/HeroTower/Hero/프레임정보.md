# Hero (러버덕) 프레임 정보

- 하드웨어 공격. 셀 48×48, pivot = 발밑 가운데 (0.5, 0.104). `.meta` 포함 (PPU 60)
- 무기: 검은 고무 망치 (평소 어깨에 짊어짐). 표정: 부리 쪽으로 기운 눈썹
- 레벨별 장비 (노란 오리 몸 유지): Lv1 빨간 머리띠 / Lv2 머리띠·가죽 가슴띠·강철 어깨 보호대 / Lv3 강철 투구·가슴판·양 어깨 보호대, 망치에 강철 띠 / Lv4 금 테두리 강철 갑옷·파란 보석·빨간 깃털·망토, 큰 망치에 금 띠
