# HeroTower (디버그 룸) 프레임 정보

- `.meta` 포함 (Unity 6000.3, PPU 100, Point 필터, 압축 없음). pivot = 받침 바닥 가운데
- 셀 크기: Lv1~2 96×128, Lv3 96×144, Lv4 96×160
- 고정 정체성: 흰 실험실 바닥 + 왼쪽 디버그 콘솔(빨간 브레이크포인트) + 가운데 오른쪽 유리 리스폰 캡슐
- 레벨업: Lv2 모니터 추가·케이블, Lv3 강철 프레임·경광등, Lv4 금색 장식·지붕 위 황금 오리 상
